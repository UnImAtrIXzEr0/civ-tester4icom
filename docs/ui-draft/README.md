# UI draft / Oberflächenentwurf

**EN**

Approved user-interface draft of 2026-10-23 (specification section 12). The files are design sources (`.dc.html`) and need the design tool's runtime (`support.js`) to render; read them as source.

| File | View |
| --- | --- |
| `Main.dc.html` | 1 · Sequence editor (main window) |
| `Katalog.dc.html` | 2 · Device catalog |
| `Lauf.dc.html` | 3 · Run and bus monitor |
| `Simulator.dc.html` | 4 · Simulator |
| `Kapazitaet.dc.html` | 5 · Bus capacity test |

Rules:

1. The specification takes precedence. The draft defines layout and interaction only.
2. All numbers, times and readings in the draft are examples, not measurements.
3. Not in the draft, built from the specification text: emergency-stop window and release dialog (P15), S-meter and power calibration (P22, P23), settings profiles with questionnaire (P24), light/dark mode and language switching (P25).
4. Language: the default is the system language (specification section 12), not English as the draft's note says.

Changes against the original draft: project-specific example names replaced with neutral ones ("Startabfrage", "Eigener Befehlssatz", "Abfrage-Last 1/2"); source reference set to the 2025 edition; the simulator option "take response delay from recording" removed, because it is not part of the specification.
